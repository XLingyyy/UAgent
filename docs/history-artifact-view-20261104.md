# 历史构建与修复记录只读查看（2026-11-04）

本切片补齐 T08 历史详情的可查证性：原生构建回执、单文件修复前备份及修改结果已有持久记录，现在可在历史运行详情的“保存的构建与修复记录”区查看。修复前备份展示保存的原始源码与当时计划写入的内容，同时保留完整 JSON 记录和 SHA-256。构建回执可查看完整保存的日志和退出结果。

读取仅使用项目 ID、运行 ID 和三个固定的已保存引用；不接收路径，不读取当前用户工程，不授予执行或恢复写入权限。原生端沿用可信窗口及 ManagedRunStore，只查询指定项目/运行已引用的 blob，校验完整长度和哈希。前端再次核对请求绑定及原历史引用的哈希，并隔离任务切换后的迟到响应。JSON/源码作为文本显示，不解释为 HTML 或命令。

单条记录显示上限为 2 MiB（内容响应限制，不是内存准入/系统保留门槛）；超过限制、丢失、损坏或不是完整 JSON 均明确失败，不将截断内容冒充完整备份。历史计划不代表文件当前状态，也不能证明后续重建成功。
