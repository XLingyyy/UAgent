## r14 修复内容

### 协作与界面

协作/工作流配置移到独立侧栏，保持输入区位置；Codex 会话按需打开，设置往返保留运行组件与草稿。既有 UI 验证覆盖 1366×768、1024×720，配置开关前后输入区尺寸稳定，小窗口无横向溢出。

### 工具参数的有界纠正

复现了模型给只读工具传入 `limit=200/100`，而工具上限为 25，导致成员整体失败并取消另一成员的问题。只对未发生读取的 `invalid_tool_limit` 返回固定约束供模型纠正；父任务与成员共享最多两次反馈，不扣实际读取额度。越权路径、权限及其他错误不转成可绕过的重试，调用 ID 保持唯一。

### 持久化时间和角色

- 无新事件、仅追加工具回复的检查点，以最近一次有效 ACK 的时间为下界，防止时间倒退。
- 原生协作调用接受已配置成员和 `synthesizer`，仅动态分工接受 `planner`。未知角色、未配置成员、重复调用 ID 等仍拒绝。
